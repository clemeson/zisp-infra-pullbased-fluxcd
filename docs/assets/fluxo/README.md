# Ícones do fluxograma

Os SVGs deste diretório são cópias locais para que `docs/fluxo-gitops.html` abra sem conexão com um serviço de ícones.

- `github`, `actions`, `docker`, `aws`, `flux`, `kubernetes`, `helm`, `letsencrypt`, `redis`, `s3`, `supabase`, `postgresql` e `azure`: coleção `logos` da [Iconify](https://icon-sets.iconify.design/logos/).
- `ecr.svg`: ícone Amazon Elastic Container Registry do pacote de [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/), obtido pelo [espelho de SVGs](https://github.com/icacho-dev/aws-architecture-icons).

As marcas pertencem aos respectivos titulares.
